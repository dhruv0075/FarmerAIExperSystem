# Data provenance

Crop_recommendation.csv: 2200 rows, 22 classes, 100 rows/class; features N/P/K/temperature/humidity/ph/rainfall; target label. No missing feature values or exact duplicates; numeric bounds checked. Original provider, license, geography and collection period are not established by the repository. Similarity to a widely circulated benchmark is not provenance verification. No nationwide accuracy claim is justified.

crop_knowledge.json is locally configured knowledge generated by a script with institution names but no precise traceable references. Treat ranges as unvalidated educational heuristics. Economic projections are withheld without verified_source_url. Unit compatibility with actual soil laboratory reports needs verification.

market_data.json and resource_catalog.json were generated locally. They are preserved for audit but excluded from operational data loaders. No live prices, stock, seller identities or history may be inferred from those fixtures.

Weather: Open-Meteo modeled conditions/forecast, not on-farm sensor observations. Farmer activities/expenses/sales/soil are explicitly farmer-entered.

Disease screening: the repository contains a MobileNetV3 Small checkpoint (`agriwise_disease_model/best_model.pth`), a 38-class mapping and inference code. The full PlantVillage image dataset is external and is not bundled. The checkpoint's exact training data/split, provenance and training metrics are not established; no labeled calibration, independent held-out or real-world evaluation manifest is present. Disease performance is unmeasured. The UI presents only an unverified same-crop suggestion, not a confirmed diagnosis. See `disease_detection.md`.
